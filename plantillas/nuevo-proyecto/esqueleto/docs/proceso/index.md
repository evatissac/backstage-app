## Diagramas

Para agregar un diagrama:

1. Dibújalo en [draw.io](https://app.diagrams.net) (o con la extensión de
   draw.io de VS Code) y guárdalo como **`.drawio.svg`**. Ese formato se ve
   como imagen y se puede volver a abrir y editar en draw.io.
2. Súbelo a esta carpeta, `docs/proceso/`. Desde GitHub: *Add file → Upload files*.
3. Enlázalo aquí como imagen:

```markdown
![Proceso actual](proceso-actual.drawio.svg)
```

En el portal se puede ampliar y recorrer con la rueda del ratón.
