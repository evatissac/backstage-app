# Decisiones

Cada decisión importante (una tecnología, una forma de integrar, un cambio de
alcance) se registra en un archivo propio, numerado y que no se borra. Si una
decisión cambia, se escribe una nueva que la reemplaza.

Para agregar una: copia `0001-stack-inicial.md` con el número siguiente,
complétala y añádela a `nav` en `mkdocs.yml`.

| # | Decisión | Estado |
|---|---|---|
| [0001](0001-stack-inicial.md) | Stack inicial | Propuesta |
